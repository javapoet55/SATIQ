# PrepOrbit AI typography assets

Manrope variable (200–800) is used for the PrepOrbit AI wordmark. Lora variable (400–700) is used for page and section headings. Original, unmodified font files are served from this application; no third-party font requests occur at runtime. SIL Open Font License texts are included beside each font.

Source: https://github.com/google/fonts/tree/5bb28733cec313b63fbd415b574b5ae35c8aa8b8/ofl (manrope and lora directories).
